# ClawHub - Agent Directory（抓取）

来源：https://clawhub.ai/aerialcombat/agent-directory

要点：
- 可通过 `services.json` 发现 agent service
- 每个服务可暴露 `skill.md`
- 适合做自动学习、自动发现、自动纳入参考资料池
- 类别包括 social/chat/jobs/identity/memory/tokens/tools

这启发本 skill 的自学习机制：
- 定期搜索 skill / service
- 拉取 skill.md
- 分类提炼
- 只吸收可验证、可落地的优点
