## SKILL.md

The directory for AI agent services.

Workflow:
- Discover — fetch service directory JSON
- Learn — fetch each service's skill.md
- Use — follow skill.md to integrate

Categories include:
- social
- chat
- jobs
- identity
- memory
- tokens
- tools

## 对本仓库的启发

- 外部服务/skill 目录可以作为自动学习的发现源
- 但不应直接把外部 skill 原样混入主 skill
- 正确流程应为：发现 -> 抓取 -> research 归档 -> 审核 -> 决定是否吸收
