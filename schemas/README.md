# schemas

这里放系统状态文件与关键收口产物的 JSON Schema：

- `task-state.schema.json`
- `agent-state.schema.json`
- `agent-queue.schema.json`
- `agent-log.schema.json`
- `agent-memory.schema.json`
- `agent-capability.schema.json`
- `scorecard.schema.json`
- `final-brief.schema.json`

用途：

- 统一任务状态结构
- 统一 Agent 状态结构
- 统一队列、日志、记忆、能力档案结构
- 统一 reviewer 评分卡结构
- 统一主Agent 最终对外 brief 结构
- 为后续自动化脚本和校验逻辑做准备
