# docs

本目录现在按更接近正规工程/skill 仓库的方式分层：

## architecture/
放系统骨架、协议、调度、接管、差距分析。

## guides/
放安装、命令、演示、发布、落地说明。

## testing/
放 smoke、测试矩阵、验收脚本说明。

## research/
放外部资料提炼、方法总结、自学习吸收说明。

## 顶层文件
- `PROJECT_STRUCTURE.md`：项目整体结构总纲
- `CODE_REVIEW_NOTES.md`：本轮重构/审计结论
- `ENTRYPOINTS.md`：正式入口矩阵
- `目录结构设计.md`：中文目录设计说明
