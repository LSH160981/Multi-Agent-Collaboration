# 自动学习与审核后自进化

这份文档对应脚本：`scripts/analysis/auto_evolve_learning.py`

目标不是“自动乱改仓库”，而是：

1. 自动抓取候选资料
2. 先落到本地 `research/auto/`
3. 生成本轮学习摘要
4. 可选交给审核Agent输出结构化审查结果
5. 再由主Agent决定是否吸收进主 skill 或代码

---

## 运行方式

### 只抓取并落本地

```bash
./scripts/analysis/auto_evolve_learning.py
```

### 抓取后交给审核Agent给建议

```bash
./scripts/analysis/auto_evolve_learning.py --with-review
```

---

## 输出内容

- `research/auto/raw/*.html`：抓取下来的原始页面
- `research/auto/learning-summary-*.md`：本轮学习摘要
- `research/auto/learning-packet-*.json`：结构化学习包

---

## 审核原则

审核Agent 重点回答：
- 哪些内容值得吸收
- 哪些不要照搬
- 哪些应该先补代码
- 哪些只需补文档
- 哪些会违反主Agent唯一用户出口规则

---

## 为什么这样设计

因为“自动学习”如果直接改主 skill，很容易出现三个问题：

1. 把噪音也吸收进来
2. 把不适合 OpenClaw 原生 session 的做法硬搬进来
3. 破坏现有规则边界

所以本项目采用：

> **先学习，后审核，再吸收。**

这是更稳的自进化方式。
