# 测试脚本

安装完 Multi-Agent-Collaboration 后，建议按下面顺序验收。

## 1. 安装自检
```bash
./scripts/install-selfcheck.sh
```

## 2. 最小可用测试集
```bash
python3 tests/test_agent_handshake.py
python3 tests/test_silent_task.py
python3 tests/test_recovery_pipeline_smoke.py
```

## 2.5 一键全链路验收
```bash
python3 tests/test_full_acceptance.py
```

这条链会统一串起：
- agent 两两互问
- 静默任务测试
- runtime orchestrator smoke
- stage3 smoke
- 恢复测试

如果当前机器还没准备好完整 agent/runtime 环境，可先跳过重阶段：

```bash
python3 tests/test_full_acceptance.py --skip-runtime --skip-stage3
```

这 3 个覆盖：
- 角色互认
- 静默任务
- 恢复闭环

## 3. 进一步 smoke
```bash
python3 tests/test_runtime_orchestrator_smoke.py
python3 tests/test_stage3_smoke.py
```

## 4. demo 与排障

### 原生 session demo
```bash
./scripts/runtime_sessions.py "/mac 调研最近 30 天值得关注的 OpenClaw 多Agent 项目，并给出改造建议"
```

### staged pipeline demo
```bash
./scripts/run_staged_pipeline.py "/mac 调研最近 30 天值得关注的 OpenClaw 多Agent 项目，并给出改造建议"
```

### session 观测
```bash
./scripts/session_probe.py ~/.openclaw/workspace
```

## 5. 失败时先看
```bash
openclaw status
openclaw sessions --all-agents
openclaw agents list
```
