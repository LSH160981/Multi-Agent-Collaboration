# 对照手稿的落地差距清单

这份文件专门对照用户手稿，识别：哪些已经落地，哪些还只是文档/原型，哪些需要继续补代码。

## 一、已基本落地

1. **名字与方向**
   - 名字已统一为 `Multi-Agent-Collaboration`
   - 路线已明确为 **OpenClaw 原生多会话版**
   - 明确 `Agent = OpenClaw session`

2. **主Agent 唯一用户出口**
   - 在 skill 主文档中已写成硬规则
   - README / 逻辑流程 / 协议中均已体现

3. **`/mac` 显式入口**
   - 已有 `scripts/mac_cli.py`
   - 现已补齐 `skills/mac/SKILL.md`
   - 安装脚本已纳入 `/mac` 命令桥复制链路

4. **中文伪代码 / 中文执行流程**
   - 已有 `伪代码.md`
   - 已有 `逻辑执行流程.md`

5. **A/B 双组、审核Agent、检查Agent、AgentPool**
   - 文档结构已完整
   - 原型脚本已具备基础雏形

6. **研究资料沉淀**
   - 已新增 `research/` 目录
   - 已加入外部来源提炼文档
   - 已拉取部分 GitHub 仓库到本地

## 二、已经有原型，但还不算完全落地

1. **真正 agent-to-agent 通信闭环**
   - 方向已明确：用 `sessions_send`
   - 文档已补
   - 但仓库内仍需把更多原型脚本从本地 JSON/CLI 过渡到统一 session runtime 编排

2. **真正按 session 状态做 stale 检查与恢复**
   - 方向已明确：`sessions_list + sessions_history + sessions_send`
   - 但 inspect/recover 代码还需要继续接实

3. **平台级默认接管所有 agent**
   - 当前做到的是：
     - 方法论层默认接管
     - skill 层默认可见
     - `/mac` 显式命令入口
   - 真正“平台级默认主Agent就是它”还取决于 OpenClaw 平台配置与安装方式，不能只靠 skill 仓库单边实现

4. **安装后 `/mac` 是否显式可见**
   - 当前仓库已经补齐 `skills/mac` 作为显式命令桥入口
   - 纯文本 `/mac ...` 可作为强触发词
   - 但具体 UI/TUI/TG 是否把它渲染成明显命令入口，仍依赖平台端展示能力，不完全由 skill 仓库决定

5. **agent 两两握手测试自动化**
   - 需求已经清楚
   - 目前还需要补专门测试脚本

6. **静默任务测试自动化**
   - 需求已经清楚
   - 当前有 demo 和说明，但还缺完整一键回归脚本

## 三、还需要继续补代码的重点

1. **统一 runtime orchestrator**
   - 主Agent 解析任务
   - AgentPool 决策角色
   - sessions_spawn 建组
   - sessions_send 派单
   - sessions_history 审核与恢复
   - dedupe_summary 输出唯一结果

2. **任务状态机与队列文档统一 Schema**
   - 任务 JSON
   - handoff JSON
   - reviewer scorecard JSON
   - inspect heartbeat JSON

3. **JSON 通信协议执行器**
   - 不只是有协议文档
   - 还要有“读取协议 → 发到目标 session → 接收回执 → 更新状态”的实际代码

4. **自动自学习闭环**
   - 定期搜索 ClawHub / GitHub / docs
   - 拉取资料
   - 提炼差异
   - 生成改进提案
   - 由主Agent审核后再改仓库

5. **git 记忆与日志压缩策略**
   - 你要求“减少硬盘消耗”
   - 这需要后续补：
     - 日志归档规则
     - memory 摘要化
     - commit 粒度规则
     - 大文件排除规则

## 四、建议下一阶段优先级

### P1
- 把 runtime 调度全面接到 OpenClaw sessions 工具模型
- 补 agent 握手测试
- 补静默任务测试
- 补 inspect/recover 自动恢复 demo

### P2
- 补自动自学习闭环
- 补队列 / 状态 / 评分统一 schema
- 补 JSON 通信执行器

### P3
- 补平台配置层说明：如何把主Agent 入口默认切到本 skill 体系
- 补更多 UI/TUI/TG 展示说明

## 五、结论

现在这个仓库已经不是“概念草图”，而是：
- 有完整方法论文档
- 有 `/mac` 命令桥
- 有安装链路
- 有 session 命令参考
- 有研究资料库
- 有一批可运行原型

但如果要达到你手稿里那种“能长期稳定跑、自动招聘、自动恢复、自动学习、自我进化”的级别，下一步关键仍是：**把文档里定义好的角色与协议，进一步接成真实的 OpenClaw session runtime 流水线。**
