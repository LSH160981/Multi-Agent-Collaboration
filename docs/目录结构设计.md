# 目录结构设计

> 本文件保留中文说明，但当前以 `docs/PROJECT_STRUCTURE.md` 作为更高层总纲。

## 推荐目录结构

```text
Multi-Agent-Collaboration/
├── README.md
├── docs/
│   ├── PROJECT_STRUCTURE.md
│   ├── CODE_REVIEW_NOTES.md
│   ├── architecture/
│   ├── guides/
│   ├── testing/
│   └── research/
├── skills/
│   ├── Multi-Agent-Collaboration/
│   └── mac/
├── scripts/
├── schemas/
├── examples/
├── agents/
├── templates/
└── research/
```

## 设计原则

- `skills/`：真正给 OpenClaw 加载的 skill。
- `agents/`：常驻角色骨架。
- `templates/`：动态 specialist 模板。
- `scripts/`：工程实现、安装、自检、编排、恢复、测试。
- `schemas/`：结构定义。
- `examples/`：协议、输入输出、测试样例。
- `docs/`：工程文档与方法说明。
- `research/`：外部资料与本地学习副本。

## 明确清理规则

- 不再保留重复的 `skill/` 根目录。
- 外部抓取的大体量资料只放 `research/`，不混进 skill 主体。
- 文档逐步按 architecture / guides / testing / research 分层。
- 新脚本必须写注释，核心公共逻辑应尽量下沉为 helper。
