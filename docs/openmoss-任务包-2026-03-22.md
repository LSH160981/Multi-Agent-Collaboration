# OpenMOSS 任务包：优化 Multi-Agent-Collaboration Skill

## 任务目标
以 OpenMOSS 为基础、现有手稿为辅，系统性优化 `/root/.openclaw/workspace/Multi-Agent-Collaboration`，把 skill 升级为 **OpenClaw 原生多会话协作系统**。

## 硬性目标
- 名字保持：`Multi-Agent-Collaboration`
- 定位：OpenClaw 原生多会话版（Agent = OpenClaw session）
- 安装与使用简单
- 默认平台级接管所有 agent
- 安装后用户直接与 skill 创建的主Agent对话
- 支持 `/mac XXX任务`
- 普通对话默认也应走该 skill 的协作能力
- 主Agent是唯一允许与用户通信的 Agent
- 其他 Agent 与后续新建 Agent 禁止直接联系用户
- agent 之间使用 JSON 通信
- 支持群聊 / 点对点 / 上下文共享
- 所有 agent 有独立记忆、日志、能力、任务队列
- 动态招聘与淘汰 specialist；至少支持 A/B 两组竞争策略
- 包含审核、检查、恢复、消息去重、静默任务测试、互认测试
- 提供中文伪代码文件与中文逻辑执行流程文件
- 使用 git 记录记忆/日志/产物，commit 信息用中文，注意减少硬盘消耗
- 具有持续自学习与优化能力

## 实施原则
1. 优先学习已有优秀作品，不闭门造车。
2. 先提炼项目骨架、伪代码、执行逻辑、通信方式，再补代码。
3. dispatch / inspect / recover / score / dedupe / orchestrator 必须逐步串起来。
4. 真正基于 OpenClaw session 与 sessions_send 的 runtime orchestration，而非只生成静态 JSON。
5. 检查所有伪代码是否需要补到具体代码；需要则补。
6. 严格消息治理：主Agent向用户发消息前必须去重、合并异步回执、删掉中间噪音，只保留最新有效结论。
