# 演示跑通手册

这份手册用于把 Multi-Agent-Collaboration 从“仓库结构”跑成“能看懂、能验证、能恢复”的系统。

---

## 1. 安装 skill

把以下两个 skill 安装到 OpenClaw 可见路径：
- `skills/Multi-Agent-Collaboration/`
- `skills/mac/`

或者直接运行：

```bash
./scripts/default-takeover-setup.sh
```

---

## 2. 初始化目录

```bash
./scripts/init-mac-system.sh
```

---

## 3. 自检

```bash
./scripts/install-selfcheck.sh
```

---

## 4. 看 OpenClaw 命令参考

```bash
openclaw help
openclaw agent --help
openclaw sessions --help
openclaw agents --help
cat docs/openclaw-agent-session-commands.md
```

---

## 5. 先跑三类基本测试

### 5.1 握手测试
```bash
./scripts/test_agent_handshake.py
```

### 5.2 静默任务测试
```bash
./scripts/test_silent_task.py
```

### 5.3 恢复烟雾测试
```bash
./scripts/test_recovery_pipeline_smoke.py
```

---

## 6. 跑一个原生 session demo

```bash
./scripts/runtime_sessions.py "/mac 调研最近 30 天值得关注的 OpenClaw 多Agent 项目，并给出改造建议"
```

看输出目录：
- `examples/generated/native-sessions/`

重点观察：
- `task-packet.json`
- `group-plan.json`
- `native-session-results.json`

---

## 7. 跑 staged pipeline demo

```bash
./scripts/run_staged_pipeline.py "/mac 调研最近 30 天值得关注的 OpenClaw 多Agent 项目，并给出改造建议"
```

如果要观察中断恢复，可以只跑到某阶段再继续。

---

## 8. TUI / 多窗口观察建议

如果你想看到多个 agent 的真实协作过程：

1. 打开多个 SSH 会话
2. 分别执行 `openclaw tui`
3. 用 `/agent` 切到不同 agent
4. 对比不同 agent 的 session 是否独立

这是调试多 agent 行为非常有效的方式。

## 10. 目标

跑通后，你应该能确认：
- 主Agent 如何接管复杂任务
- `/mac` 如何显式进入多会话模式
- AgentPool 如何招聘或复用角色
- specialist 如何执行并交接
- 审核Agent 如何打分与驳回
- 检查Agent 如何巡检与恢复
- 为什么最终只有主Agent对用户输出
