# 演示跑通手册

这份手册的目标只有一个：把仓库从“文件存在”跑到“链路可验证”。

## 推荐最短路径

### 1. 安装
```bash
./scripts/default-takeover-setup.sh
```

### 2. 自检
```bash
./scripts/install-selfcheck.sh
```

### 3. 跑核心测试
```bash
python3 tests/test_agent_handshake.py
python3 tests/test_silent_task.py
python3 tests/test_recovery_pipeline_smoke.py
```

### 4. 跑一个 session demo
```bash
./scripts/runtime_sessions.py "/mac 调研最近 30 天值得关注的 OpenClaw 多Agent 项目，并给出改造建议"
```

## 如果要继续验证

### staged pipeline demo
```bash
./scripts/run_staged_pipeline.py "/mac 调研最近 30 天值得关注的 OpenClaw 多Agent 项目，并给出改造建议"
```

### 多窗口观察
1. 打开多个 SSH 会话
2. 分别执行 `openclaw tui`
3. 用 `/agent` 切到不同 agent
4. 对比不同 agent 的 session 是否独立

## 跑通后的判断标准

你至少应该能确认：
- 主 Agent 如何接住复杂任务
- `/mac` 如何显式进入多会话模式
- session 是否真的复用 / 派发 / 收口
- 恢复链路是否可用
- 最终是否仍只有主 Agent 对用户输出
